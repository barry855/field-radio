GAMMA / DELTA Field Radio Chat

Quick-Start Guide for Two-Station Peer-to-Peer Text & Morse Comms

Gamma and Delta are a paired set of simple web pages that let two stations exchange text chat over a direct peer-to-peer link, with an optional built-in Morse code sender and receiver. One station opens GAMMA.html and the other opens DELTA.html. No installation is required — both pages run in any modern web browser on a phone, tablet, Chromebook, or PC.

1. Getting Connected

Both operators must agree on a shared channel code beforehand (over voice, previously, or by any other means). The code can be any short string of letters and/or numbers — for example 123456 — but both stations must enter the code exactly the same way.

  1. Open GAMMA.html on one device and DELTA.html on the other.
  2. On the login screen, type the agreed channel code into the Channel Code box.
  3. Watch the small status light below the box — it will show SEARCHING, then REACHABLE (green) once the other station has entered the same code, or OFFLINE (red) if not yet detected.
  4. Tap CONNECT. Both stations should do this within a minute or so of each other.
  5. The status bar at the top will progress from OFFLINE → ONLINE — DIALLING → LINKED (green light). Once LINKED, chat is ready.
Tip: the connection is made over the public internet using a relay/signalling service, so both devices need an active internet connection (Wi-Fi or cellular data) — this is not a direct RF link.

2. Using the Chat Screen

3. Sending Morse Code to the Other Station

Either station can send a message as Morse code instead of plain text. The receiving station will both see the text and, if their Speaker is switched on, hear it played as Morse tones.

  1. Type your message in the message box as normal.
  2. Choose a speed from the Morse Speed dropdown (10–30 WPM).
  3. Tap Send as Morse instead of Send.
  4. You will hear your own message as a sidetone immediately. The other station hears it too (if their Speaker is ON) and also sees the text in their chat window.
Speaker On/Off — controls whether your device plays incoming Morse audio. Turn it off if you only want to read the text. Your setting is remembered between sessions.

4. Practicing Morse Code (No Connection Needed)

Both GAMMA and DELTA include a Morse Practice tab at the top of the page, next to Chat. This works completely offline and does not require the other station to be present.

SectionPurpose
Speed & ToneSet the practice WPM (5–30) and tone pitch (500–700 Hz), separate from the chat Morse speed.
ListenType text and tap Play to hear it in Morse. Tap Random Group for a random 5-letter group — good for copy practice.
QuizHear a random letter played in Morse, type what you heard, and tap Submit. Tracks Correct, Wrong, Streak and Accuracy.
A separate stand-alone page, MORSE.html, offers a fuller trainer with Listen, Decode (including a tap-key for sending your own Morse), Quiz, and a full character Reference table — useful for solo practice away from the Gamma/Delta link.

5. Quick Reference

Status LightMeaning
GreyOffline / not yet connected
Cyan, blinkingOnline, attempting to dial the other station
Green, solidLinked — chat is ready
RedError — check the Debug Log
If the connection stalls on "OFFLINE" or repeatedly fails to link, double-check that both stations entered the identical channel code — this is by far the most common cause of connection trouble.
