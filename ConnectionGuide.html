⚡ FIELD RADIO — CONNECTION GUIDE

Peer-to-peer WebRTC voice & chat — quick reference for setup and troubleshooting

1Before You Start

  • Both devices need a modern browser (Chrome recommended; Android Chrome works best for camera/mic).
  • Both devices need an internet connection (Wi-Fi or mobile data) — this app connects through the internet, not directly device-to-device on a local network.
  • Open ALPHA.html on one device and BRAVO.html on the other. Either device can run either file — there's no required order, but only one of each per session.
Tip: On Android, allow microphone and camera permission prompts when they appear — if denied, you'll need to re-enable them in the browser's site settings.

2The Two Roles

ALPHA.html

Initiates the call connection. Opens its data channel first once both sides are present.

Use on whichever device you consider the "base" or primary unit — but it works fine either way.

BRAVO.html

Waits for ALPHA's connection request and accepts it.

Functionally identical chat/voice/video UI — only the connection-handshake role differs.

Either unit can be opened first. Whoever opens first simply waits for the other to join using the same session code.

3Connecting — Step by Step

  1. On one device, open ALPHA.html.
  2. On the other device, open BRAVO.html.
  3. Agree on a 6-character session code (letters/numbers — both sides must enter the same code). Spaces are ignored and lowercase is automatically converted to uppercase.
  4. Type the code into the session code field on both devices.
  5. Press Enter or tap the connect/start button on each device.
  6. Wait a few seconds — the status will update once both sides find each other and the connection completes.

5If the Connection Drops

  • A "RECONNECTING" overlay with a 30-second countdown appears automatically — the app tries to silently recover the connection in the background during this time.
  • If it doesn't recover within 30 seconds, the app returns to the login/code-entry screen — just re-enter the same code and reconnect.
  • On Android, if the page seems stuck after switching apps or locking the screen, tap Refresh (↺) on either device.

6Quick Troubleshooting

  • No audio from the other side? Check the Speaker toggle isn't muted, and on Android tap the "TAP TO HEAR AUDIO" banner if it appears.
  • Camera shows black or doesn't switch? Try Flip Cam again, or refresh the page.
  • Stuck on "connecting"? Double-check both devices entered the exact same session code (case doesn't matter, spaces are stripped).
  • One side shows "connected" but nothing comes through? Both sides should tap Refresh (↺) to force a clean reconnect.
  • Screen Share / Sys Audio buttons missing? These require desktop Chrome/Edge or Firefox — they're hidden automatically on Android since the browser doesn't support them there.
