⚡ FIELD RADIO — CHEAT SHEET

Quick reference for on-screen controls and keyboard shortcuts

Top Bar Controls

ButtonFunction
↺ RefreshReload the page to force a clean reconnect if the connection gets stuck
✕ LeaveEnd the session and notify the other side cleanly
⟳ Flip CamSwitch between front/back camera (mobile)
FS OFF / FS ONToggle full-screen chat/video view
MINI OFF / MINI ONToggle the small picture-in-picture video overlay
SEEING THEMToggle which video feed (yours / theirs) fills the main view
➤ RECORDRecord the current main feed (plus mini overlay, if visible)
Video Off / OnTurn your camera feed on or off
Audio On / OffMute or unmute your microphone
Sys Audio Off/OnCapture computer audio output and mix into your transmitted audio (desktop/Firefox only — use headphones)
Share Off/OnShare your screen (desktop only — hidden on Android)
SYS LOGToggle the technical connection/event log panel

Chat Tools

ButtonFunction
💾 SAVEExport the current chat as a printable HTML file
↩ RESTOREReload the previous session's chat history into the window
🗑 CLEARErase chat history on both sides
🔍 FINDSearch within the chat (opens the find bar)
+ (bubble)Copy a message's text (+ translation, if shown) — top-left of bubble
✕ (bubble)Delete that message for both sides — top-right of bubble

Translate Bar

ControlFunction
Language dropdownAuto-translate incoming chat messages into this language
ORIGINALRevert translation back to the system/default language
Tap/hover bubblePeek the original (untranslated) text; tap again to lock it open

Talk / Type Panel

ControlFunction
Talk/Type in ChatOpen or close the speech/text input panel
TALKStart/stop voice dictation into the input box
SENDSend the input box text to chat
ATTACHAttach a file (or drag & drop onto the panel)
LOADLoad a text file's contents into the input box
SAVESave the input box text to a file
COPYCopy the input box text to clipboard
CLEARClear the input box
Lang dropdownSet the speech-recognition (dictation) language
ORIGINALRevert dictation language to your system language
TTS Off/OnToggle auto-speak (text-to-speech) for incoming messages
Voice dropdownChoose the TTS voice used for spoken output
