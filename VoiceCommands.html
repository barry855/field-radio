⚡ FIELD RADIO — VOICE COMMANDS

Spoken commands recognized in the Talk/Type dictation box
How it works: While dictating, certain spoken words and phrases are automatically converted into punctuation, symbols, or text-editing actions instead of being typed literally. Say the word naturally as part of your sentence — e.g. "My name is Jose period" becomes "My name is Jose." Commands are not case-sensitive.

Editing Commands

SayResult
delete word / delete N wordsRemoves the last word(s) typed
delete sentence / delete N sentencesRemoves the last sentence(s)
delete message / delete N messagesClears the entire input box
scratch that / undo thatRemoves the last sentence
Numbers: N can be spoken as a word (one, two, three… ten) or a digit (1, 2, 3…). If no number is said, "delete word" / "delete sentence" removes just one.
Mis-hearings of "delete": Speech recognition sometimes mishears "delete" — the phrases "to lead", "to leed", and "the lead" are also recognized as "delete" so the editing commands above still work even if misheard this way.

Worked Example

"My name is Jose Jimenez period"→My name is Jose Jimenez.
"I live in Los Angeles period"→My name is Jose Jimenez. I live in Los Angeles.
"Eli Ipshay"→…Los Angeles. Eli Ipshay
"delete two words"→My name is Jose Jimenez. I live in Los Angeles.
"new paragraph"→(starts a new paragraph)
"the total is dollar sign 5 percent off"→the total is $5% off
"delete one sentence"→(removes the last sentence)
"delete one message"→(clears the input box entirely)
