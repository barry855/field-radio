Field Radio — Chat TabALPHA & BRAVO · Quick Reference

Connection Status

CALLING… — dialling BRAVO, waiting for answer
LINKED — audio, video and chat active
OFFLINE — not connected

Top Row (always visible)

↺ REFRESH Reconnect / reload the page without losing the session code.
✕ Leave End the session and return to the login screen.
TALK OR TYPE IN CHAT Open the speech / text input panel at the bottom. Toggles to SHOW CHAT when panel is open.

Controls Dropdown

Tap ▼ CONTROLS ▼ to expand or collapse. Two rows of buttons plus a MIC GAIN slider.

All controls affect the local device only unless stated otherwise.

Controls — Row 1

💾 SAVE Save the current chat conversation to an HTML file on your device.
↩ RESTORE Load the most recently saved chat history back into the chat window.
🗑 CLEAR Wipe all messages from the chat window (does not affect saved files).
🔍 FIND Open the find bar above the chat. Type to search, ▲ ▼ to step through matches, ✕ to close.
MINI ON / MINI OFF Show or hide the draggable mini video overlay inside the chat panel. Drag the overlay to reposition it.
⟳ Flip Cam Switch between front and rear cameras (mobile).
SYS LOG Toggle the system log panel at the bottom — shows connection events, errors and status messages.

Controls — Row 2

VIDEO REMOTE / VIDEO LOCAL Switch the main chat video underlay between the remote feed and your own local feed.
➤ RECORD / ⏹ STOP Record the current main video feed (+ mini overlay if visible) to a file. Tap again to stop and save.
Video Off / Video On Toggle your outgoing video. When off, the remote side receives no video from you.
Audio On / Audio Off Mute or unmute your microphone for the session. Mute state resets on refresh — does not persist.
Share Off / Share On Start or stop screen sharing. Your screen replaces the outgoing video feed for the remote side.

MIC Gain Slider

Drag the MIC GAIN slider (0 – 3×) to boost or reduce your outgoing microphone level in real time. Default is 1.00×. Useful on noisy environments or quiet devices.

🌐 Translate Bar

SELECT LANGUAGE Open the language picker. Type to filter. Tap a language to translate all incoming messages.
ORIGINAL Revert all messages back to the original untranslated text.

Translation is local only — the remote side sees their own language.

Talk or Type Panel (Speech Input)

Opened via TALK OR TYPE IN CHAT. Contains a text area and a row of action buttons.

TALK Hold or tap to start voice recognition. Speech appears in the text area for review before sending.
SEND Send the contents of the text area as a chat message. Enabled once there is text.
ATTACH Attach an image, video, audio file or document. Also supports drag-and-drop onto the chat panel.
LOAD Load a .txt or .md file into the text area.
SAVE Save the current text area contents to a .txt file.
CLEAR Clear the text area.
COPY Copy the text area contents to clipboard.

Chat Messages

Copy button Each message bubble has a [+] copy button in the top-right corner. Copies message text (plus translation if active) to clipboard.
File attachments Images display inline. Videos and audio play in the bubble. Other file types appear as a download link.
Find in chat Use 🔍 FIND or the find bar to search. Matches are highlighted; use ▲ ▼ to navigate.

SYS Log Panel

Collapsed by default. Tap the SYS LOG header bar to expand/collapse.

SAVE Save the log to a text file.
COPY Copy entire log to clipboard.
CLEAR Wipe the log display.
STOP / RUN Pause or resume live log updates.
